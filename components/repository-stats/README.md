# Repository Stats Card

Shows GitHub stars, forks, open issues (including pull requests) and the most recent push timestamp for **RuslanSharifov/readme-component-hub**.

Data is fetched through GitHub Actions and saved as SVG files, not rendered through a backend. Pages and README use the generated artwork. Values refresh on the hourly GitHub Actions schedule (GitHub may delay scheduled runs).

To add a card for another repository, copy this component into a new directory, choose a unique ID, edit `repository`, and submit a pull request. No GitHub API key required for readers.
